# Tarea Opcional 3 - JavaScript

Resolución de los tres ejercicios.

## Cómo ejecutar

Abrir la carpeta en Visual Studio Code, abrir una terminal y ejecutar:

```bash
node ejercicio1.js
node ejercicio2.js
node ejercicio3.js
```

## Contenido
- `ejercicio1.js`: productos de tecnología y suma de hogar.
- `ejercicio2.js`: estudiantes aprobados y cantidad de reprobados.
- `ejercicio3.js`: promedios, empleados excelentes, en riesgo y activos con promedio >= 6.
